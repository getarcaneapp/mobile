# Shared UI components

Ports of the reference app's shared SwiftUI components. **SwiftUI-tree** = returns `@expo/ui/swift-ui` elements; compose inside an existing `Host` tree (iOS only; `.ios`-only files have no Android sibling, so import them from `.ios.tsx` screens only). **Standalone** = an RN view (or its own `Host`) you can drop into any RN tree. Split files: `name.ios.tsx` / `name.android.tsx` share props in `name.types.ts`; import as `@/ui/components/name`.
